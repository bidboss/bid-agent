# 终端输入交互规范调研

> 调研并对齐 **Claude Code**、**Cursor IDE**、**VSCode Command Palette** 三款产品的终端 / 命令面板交互范式，作为本项目（`frontcode` AI 终端助手）终端增强输入的规范基准。

> **本文档定位**：规范与原则（what & why）。具体落地细节（how）见各对应设计/计划文档（如 `docs/终端增强输入.md`）。

> **最新更新**：2026-09-21，对齐「终端交互优化与指令补齐」计划——明确按键范式为 **Cursor IDE 范式 + 单选模式**，并补全 5 条新增内置指令（`/help` `/clear` `/context` `/exit` `/quit`）。

---

## 一、调研目标与对照产品

### 1.1 调研目标

从行业已成熟的 AI 终端 / 命令面板产品中提炼**通用交互规范**，解决三类问题：

| 问题 | 调研要点 |
|------|----------|
| **触发** | 什么字符触发候选列表？触发条件是什么？ |
| **按键** | 列表态下 ↑↓ / Tab / Enter / Esc / Space 各自的语义是什么？ |
| **指令** | 内置指令如何与触发符协作？哪些是必备项？ |

### 1.2 对照产品

| 产品 | 类型 | 候选列表 | 多选 | 关键差异 |
|------|------|----------|------|----------|
| **Claude Code** | AI 终端 CLI（Anthropic） | `/` 触发指令、`@` 触发文件 | **单选**为主 | 斜杠 + 文件引用，最少快捷键，新手友好 |
| **Cursor IDE** | AI IDE（编辑器内） | `/` 触发命令面板、`@` 触发文件、`#` 触发设计/上下文 | **单选** | IDE 范式：Tab = 焦点跳转，Enter = 确认，Space **不**劫持 |
| **VSCode Command Palette** | IDE 命令面板 | `Ctrl+Shift+P` 唤起 | **单选** | Tab 跳转焦点，Enter 确认，与 Cursor 同源 |
| **fzf / skim** | 终端 fuzzy finder | 整行交互模式 | **多选**（`-m` 模式专属） | 终端 CLI 行业规范：Tab = toggle 勾选，Space = 预览 |

### 1.3 行业范式分裂

终端 UI 行业存在两套**明确对立**的范式：

| 范式 | 代表 | Tab 语义 | Enter 语义 | Space 语义 |
|------|------|---------|-----------|-----------|
| **IDE 范式**（命令面板） | Cursor / VSCode | **焦点跳转** | **确认** | 原生（插入空格） |
| **fzf 范式**（终端 CLI） | fzf / skim / peco | **多选 toggle 并下移** | 确认 | 默认预览滚动，可绑 toggle |
| **AI 终端混合** | Claude Code | 焦点跳转（单选时） | 确认 | 原生 |

> **关键结论**：本项目最终决策 **Cursor IDE 范式 + 单选模式**——明确把 Tab 定位为「焦点跳转」，Enter 为「确认」，Space 不劫持。**这不是 fzf 的行业规范**，但与 Claude Code / Cursor / VSCode 一致。

## 二、各指令语义规范

### 2.1 触发符统一约定

| 触发符 | 类型 | 触发条件 | 候选源 | 选中行为 |
|--------|------|----------|--------|----------|
| `/` | `command` | 行首或空格后 `/`，且光标前无空格 | 内置指令（5 条，见下方）+ 自定义指令（`.front/commands/` 未来扩展） | 写入 `/cmdName ` 到输入行，不立即提交 |
| `@` | `file` | 行首或空格后 `@`，且光标前无空格 | 项目文件（`scanProjectFiles`，排除 `node_modules` `.front` 等） | 写入 `@[相对路径] `，文件内容作为附加段追加到消息 |
| `#` | `image` | 行首或空格后 `#`，且光标前无空格 | `.front/design/` 图片 | 写入 `#[文件名] `，图片以 `image_url` 注入多模态消息 |

### 2.2 当前内置指令（5 条）

| 指令 | 行为 | 是否写 history | 是否需要模型 |
|------|------|----------------|--------------|
| `/help` | 打印完整帮助（指令 + 触发符 + 按键） | ❌ | ❌ |
| `/clear` | 清空内存 history，磁盘会话文件保留 | ✅（清空） | ❌ |
| `/context` | 打印消息数 / token / 文件路径 / 文件大小 | ❌ | ❌ |
| `/exit` | 与 Ctrl+C 等价：清理 MCP、关闭 readline、`process.exit(0)` | ❌ | ❌ |
| `/quit` | 同 `/exit` | ❌ | ❌ |

> 历史决策：原型阶段砍掉了 `/a` / `/ask`（单轮无工具问答），后续如需要加回，保持「**不写入 history、不走工具循环**」语义。

### 2.3 退出语义统一

| 触发方式 | 路径 |
|----------|------|
| `Ctrl+C` (keypress) | `handleKeyPress` 拦截 → `onExitRequest()` |
| `/exit` `/quit`（带 `/`） | commandHandlers 表分派 → `requestExit()` |
| `exit` `quit`（裸字符串） | 主循环识别 → `requestExit()` |

## 三、文件选择（@ / #）按键规范

### 3.1 标准按键映射

| 按键 | 列表态 | 正常输入态 | 备注 |
|------|--------|------------|------|
| `↑` / `↓` | 切换焦点（循环） | 原生方向键 | Tab 与 ↓ 合并；Shift+Tab 与 ↑ 合并 |
| `Tab` | **焦点跳到下一项**（不确认） | 原生 Tab | **语义固定为「焦点跳转」，禁止作为确认按键** |
| `Shift+Tab` | 焦点跳到上一项 | 原生 Tab | 部分 Node 版本 `key.name === 'back_tab'`，需双检测 |
| `Enter` | **确认当前焦点项**（Cursor IDE 范式） | 提交整行 | 确认后**不**触发提交整行，光标停在标签之后，可继续输入 |
| `Esc` | 关闭候选，不修改输入 | 原生 | 用户主动取消 |
| `Space` | **不劫持** | 原生插入空格 | **强制约束**：列表态下空格仍走原生输入字符路径，与普通输入行为一致 |
| `Ctrl+C` | 触发退出回调 | 触发退出回调 | 全局 |

### 3.2 强制约束

1. **仅弹窗激活状态下劫持 Tab / 方向键**：正常态下 Tab 走原生（readline 默认行为，焦点跳转 / 自动补全）。
2. **Tab 语义固定为「焦点跳转」**：禁止把 Tab 当作「确认」。这与 Claude Code / Cursor / VSCode 习惯一致，与 fzf 行业规范分裂是**显式取舍**。
3. **Space 一律不劫持**：避免用户输入「带空格的过滤词」时以为在勾选，导致结果意外。**当前模式：单选，无需勾选语义。**
4. **`@[file]` / `#[img]` 选中后是「标签」，不是「立即注入」**：用户可继续输入，标签统一在 `prompts.ts#buildSendMessages` 阶段解析与注入。

### 3.3 模式区分（当前仅单选）

> 当前决策：**单选模式**。多选模式已显式排除（用户决策 2026-09-21）。

| 模式 | 候选列表行为 | 触发场景 |
|------|--------------|----------|
| **单选（当前）** | Enter 确认当前焦点项，回填一个标签 | `@` 引用一个文件、`#` 引用一张图、`/` 选一个指令 |
| 多选（未启用） | Space 切换勾选、Tab 跳转、Enter 批量确认 | 未来如支持 `@` 多文件引用时启用 |

**未来启用多选的前提条件**：
- 候选列表顶部 / 底部添加「多选模式」提示文本
- 设计「单选 ↔ 多选」切换键（如 `Shift+Enter` 或 `Ctrl+M`）
- `confirmSelection` 支持返回 `string[]`（多个已勾选项）

### 3.4 完整用例矩阵

| 场景 | 输入序列 | 结果 |
|------|----------|------|
| 引用文件 | `@`、`s`、`r`、`c`、`/`、`a`、`p`、`p`、`↓`、`Enter` | input 写入 `@[src/lc/app.ts] `，AI 收到 `## src/lc/app.ts` 附加段 |
| 引用图片 | `#`、`t`、`e`、`s`、`t`、`Enter` | input 写入 `#[test.png] `，AI 收到 `image_url.data:image/png;base64,...` |
| 选择指令 | `/`、`c`、`l`、`Enter` | input 写入 `/clear `，再 Enter 触发 `runClearCommand` + 清空 history |
| 焦点跳转（确认前） | `@`、`a`、`p`、`p`、`↓`、`↓`、`↓` | 焦点循环切换，不确认 |
| 单选 Esc 取消 | `@`、`Esc` | 列表关闭，`currentLine` 不变（仍是 `@`） |
| Space 原生保留 | `/`、`c`、`l`、`Space`（列表关后） | 空格正常插入：当前行变成 `/cl ` |
| Space 在列表内 | `/`、`Space`（列表开着） | 空格插入 currentLine，列表继续按空格后内容筛选 |
| Ctrl+C 全局 | 任意时刻 | 触发 `requestExit()` |
