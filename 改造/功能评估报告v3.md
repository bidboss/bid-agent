## 三、关键架构变化详解

### 3.1 终端输入层：`input/index.ts` → `input.ts`（重大重构）

| 维度 | 上次（v2）382 行 | 本次（v3）**245 行** |
|------|-----------------|---------------------|
| 库依赖 | 原生 readline（手写 keypress） | `@inquirer/prompts`（input/select/search） |
| 触发符检测 | 实时按键（敲 @ 即弹候选） | **回车后检测**（行末是 `/ @ #` 才弹） |
| 状态机复杂度 | 高（normal/listState/keypress 重绘） | 低（loop + while + isCanceled） |
| 交互体验 | Cursor IDE 范式（Tab=焦点跳转） | **简化范式**（回车确认） |
| 候选列表 | 方向键/Tab/Shift+Tab/Enter/Esc/Space | inquirer 原生（↑↓ 聚焦、Enter 确认、ESC 取消） |
| 代码量 | 382 | -36% |
| 取消语义 | `setOnExitRequest` 回调 | `CancelPromptError` / `ExitPromptError` |

**对外接口**（保持兼容或变化）：

```typescript
// 新版核心 API

// 返回类型

  | { action: 'message'; input: ComposedInput }  // 普通消息

```
